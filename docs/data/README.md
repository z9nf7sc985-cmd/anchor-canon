# Anchor Canon — data folder

This folder holds the **book catalog** and, later, locked public-domain text files.

## What is here now

- `books.json` — empty book stubs only (ids, titles, sections, chapter placeholders, `status: "empty"`).
- No verse bodies. No invented wording. No model-generated scripture.

## What will be added later

Only **public-domain** sources will be locked here, for example:

- Public-domain Ethiopic / broader canon materials (including 1 Enoch where rights allow)
- Dead Sea Scrolls–related public-domain editions or transcriptions where rights allow
- Modern-English drafts that never rewrite a single verse in isolation

Texts will be locked files. Coincidence search will run only on those locked files once they exist.

## Reading rules

Site shell is owned here. Reading / animation rules for Bible Shorts are owned separately (Jesus / Bible Shorts Animator). This scaffold does not train or host a custom language model.
